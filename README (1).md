# Image Captioning AI

This is a deep learning-based image captioning model that generates natural language descriptions for uploaded images using the BLIP model.

## Model
Salesforce/blip-image-captioning-base
## How it works
Upload an image → AI generates a caption describing the scene.

## Features
- Image upload
- Automatic caption generation
- Lightweight and fast
